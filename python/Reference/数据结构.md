# 列表详解
 ## **list.append(value,/)** 
 > 在列表末尾添加一项

```python
a = []  
a.append(1)   
print(a) # list = [1]
```

##  **list.extend(iterable,/)** 
> 通过添加来自 iterable 的所有项来扩展列表
```python
a.extend([2,3])  
print(a) # [1, 2, 3] 且不改变对象
```
## list.insert(_index_, _value_, _/_)
> 在指定位置插入元素。第一个参数是插入元素的索引，因此，`a.insert(0, x)` 在列表开头插入元素
```python
a.insert(0,0)  
print(a) # [0, 1, 2, 3]
```
## list.remove(_value_, _/_)
> 从列表中移除第一个值为 _value_ 的条目。 如果无此条目则会引发 [`ValueError`](https://docs.python.org/zh-cn/3.14/library/exceptions.html#ValueError "ValueError")。

```python
a.remove(2)  
print(a) #[0, 1, 3]  
a.remove(5) # ValueError: list.remove(x): x not in list
```

## list.pop(_index=-1_, _/_)
> 移除列表中给定位置上的条目，并返回该条目。 如果未指定索引号，则 `a.pop()` 将移除并返回列表中的最后一个条目(因为index是可选参数，默认值-1，代表最后一个)。 如果列表为空或索引号在列表索引范围之外则会引发 [`IndexError`](https://docs.python.org/zh-cn/3.14/library/exceptions.html#IndexError "IndexError")。
```python
a.pop()  
print(a) # [0, 1]  
a.pop(3) # IndexError: pop index out of range
```
## list.clear()
> 移除列表中的所有项。 类似于 `del a[:]`
```python
a.clear()  
print(a) # []
```

## list.count(_value_, _/_)
> 返回列表中 _value_ 出现的次数。
```python
a[:] = [1,2,3,4,5,4,3,2,1]  
print(a.count(1)) # 2  
print(a.count(5) )# 1
```
## list.sort(_*_, _key=None_, _reverse=False_)
> 原地排序列表中的元素 (要了解自定义排序参数，详见 [`sorted()`](https://docs.python.org/zh-cn/3.14/library/functions.html#sorted "sorted"))。

```python
a = [2,1,4,5,3]  
a.sort()  
print(a) # [1, 2, 3, 4, 5]
```
## list.reverse()
> 翻转列表中的元素。
```python
a=[1,2,3,4,5]  
a.reverse()  
print(a) # [5, 4, 3, 2, 1]
```
## list.copy()
> 返回列表的浅拷贝。 类似于 `a[:]`
> 这里我的理解是创建了一个新的列表对象，列表对象里引用的元素还是同一个

## 用列表实现堆栈
堆栈的特点是`last in fisrt out`,可通过`append`方法添加元素到末尾，然后通过`pop`方法从列表末尾获取元素
## 用列表实现队列
队列的特点是`first in first out`,但是用列表实现效率很低，因为从列表头部插入或删除数据必须移动其他元素，所以实现队列用[`collections.deque`](https://docs.python.org/zh-cn/3.14/library/collections.html#collections.deque "collections.deque")
```python
from collections import deque;  
  
queue = deque(['a', 'b', 'c'])  
queue.append('d') # [a,b,c,d]  
queue.append('e') # [a,b,c,d,e]  
  
queue.popleft() # a  
  
queue.popleft() # b  
  
print(queue) # deque(['c', 'd', 'e'])
```
## 列表推导式

列表推导式创建列表的方式更简洁。常见的用法为，对序列或可迭代对象中的每个元素应用某种操作，用生成的结果创建新的列表；或用满足特定条件的元素创建子序列![](../assets/Pasted%20image%2020260520142412.png)
上面通过循环的方式构建了一个列表，但是同时也有一个副作用，那就是循环结束`x`依然存在。所以通过以下方式构建列表
```python
list(map(lambda x: x**2, range(10)))
```
或者
```python
[x**2 for x in range(10)]
```
列表推导式的方括号内包含以下内容：一个表达式，后面为一个 `for` 子句，然后，是零个或多个 `for` 或 `if` 子句。结果是由表达式依据 `for` 和 `if` 子句求值计算而得出一个新列表。 举例来说，以下列表推导式将两个列表中不相等的元素组合起来：
``` python
[(x, y) for x in [1, 2, 3] for y in (3, 1, 4) if x != y]
# [(1, 3), (1, 4), (2, 3), (2, 1), (2, 4), (3, 1), (3, 4)]
```
列表推导式语法：

### \[expr for x in it\] 基础遍历
```python
for x in it:
	return expr
```

### \[expr for x in it if cond\] 带过滤条件
```python
for x in it:
	if cond:
		return expr
```
### \[expr1 if cond else expr2 for x in it\] 条件表达式
```python
for x in it:
	if cond:
		return expr1
	else:
		return expr2
```
### \[expr for x in A for y in B\] 双层for
```python
for x in A:
	for y in B:
		return expr
```
### \[expr for x in A for y in B if cond\] 双层for + 条件
```python
for x in A:
	for y in B:
		if cond:
			return expr
```
### \[expr for x in A if cond1 for y in B if cond2\]
```python
for x in A:
	if cond1:
		for y in B:
			if cond2：
				return expr
```
### \[item for row in matrix for item in row\] 多层嵌套
```python
for row in matrix:
	for item in row:
		return item
```
## del 语句
可以按索引而不是按值从一个列表移除条目：即使用 [`del`](https://docs.python.org/zh-cn/3.14/reference/simple_stmts.html#del) 语句，与pop方法的区别是del 没有返回值，且del可以按照切片删除数据
```python
a = [-1, 1, 66.25, 333, 333, 1234.5]
del a[0]
a
[1, 66.25, 333, 333, 1234.5]
del a[2:4]
a
[1, 66.25, 1234.5]
del a[:]
a
[]
```

del可以删除整个变量，此后再引用这个变量会报错
```python
a = [1,2,3]  
del a  
print(a)
# NameError: name 'a' is not defined
```

## 集合
Python 还包括一个表示 [集合](https://docs.python.org/zh-cn/3.14/library/stdtypes.html#types-set) 的数据类型。 集合是由不重复元素组成的无序多项集。 基本用法包括成员检测和消除重复元素。 集合对象还支持合集、交集、差集和对称差集等数学运算。
创建集合用花括号或 [`set()`](https://docs.python.org/zh-cn/3.14/library/stdtypes.html#set "set") 函数。注意，创建空集合只能用 `set()`，不能用 `{}`，`{}` 创建的是空字典

## 字典
 与以连续整数为索引的序列不同，字典是以 _键_ 来索引的，键可以是任何不可变类型；字符串和数字总是可以作为键。
 ```python
 {key1: vallue1, key2:value2}
 ```
 可以把字典理解为 _键值对_ 的集合，但字典的键必须是唯一的。花括号 `{}` 用于创建空字典。另一种初始化字典的方式是，在花括号里输入逗号分隔的键值对，这也是字典的输出方式。
 <br/>
 可以把字典理解为 _键值对_ 的集合，但字典的键必须是唯一的。花括号 `{}` 用于创建空字典。另一种初始化字典的方式是，在花括号里输入逗号分隔的键值对，这也是字典的输出方式。
 <br/>
 字典的主要操作是通过键来存储值并根据给定的键来提取值。 通过 `del` 也可以删除键值对。 如果你使用已存在的键进行存储，则与该键相关联的旧值将丢失。字典的主要操作是通过键来存储值并根据给定的键来提取值。 通过 `del` 也可以删除键值对。 如果你使用已存在的键进行存储，则与该键相关联的旧值将丢失。

## 循环的技巧
当对字典执行循环时，可以使用 [`items()`](https://docs.python.org/zh-cn/3.14/library/stdtypes.html#dict.items "dict.items") 方法同时提取键及其对应的值。
```python
knights = {'gallahad': 'the pure', 'robin': 'the brave'}
for k, v in knights.items():
    print(k, v)
# gallahad the pure
# robin the brave
```
对序列进行循环时，用 [`enumerate()`](https://docs.python.org/zh-cn/3.14/library/functions.html#enumerate "enumerate") 函数可以同时取出位置索引和对应的值：
```python
for i, v in enumerate(['tic', 'tac', 'toe']):
    print(i, v)
# 0 tic
# 1 tac
# 2 toe
```
同时循环两个或多个序列时，用 [`zip()`](https://docs.python.org/zh-cn/3.14/library/functions.html#zip "zip") 函数可以将其内的元素一一匹配：
```python
questions = ['name', 'quest', 'favorite color']
answers = ['lancelot', 'the holy grail', 'blue']
for q, a in zip(questions, answers):
    print('What is your {0}?  It is {1}.'.format(q, a))
# What is your name?  It is lancelot.
# What is your quest?  It is the holy grail.
# What is your favorite color?  It is blue.

x1 = [0,1,2,3]  
x2= '零','一','二','三'  
x3 = {'zero','one','two','three'}
for i1, i2, i3 in zip(x1, x2, x3):  # 序列类型都支持
    print(i1, i2, i3)
# 0 零 zero
# 1 一 two
# 2 二 one
# 3 三 three

y1 = [0,1,2,3]  
y2 = ['zero','one','two']
for i1,i2 in zip(y1, y2):  # 序列长度不一致时，只遍历到最小长度的序列
    print(i1, i2)

# 0 zero
# 1 one
# 2 two

```

为了逆向对序列进行循环，可以求出欲循环的正向序列，然后调用 [`reversed()`](https://docs.python.org/zh-cn/3.14/library/functions.html#reversed "reversed") 函数：
```python
basket = ['apple', 'orange', 'apple', 'pear', 'orange', 'banana']
for i in sorted(basket):
    print(i)
apple
apple
banana
orange
orange
pear
```
