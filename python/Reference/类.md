## 命名空间与作用域
> 命名空间本质上是一个**字典（Dictionary）**，里面存的是 `变量名 -> 对象引用` 的映射。Python 中主要有三种命名空间：

| 命名空间   | 声明周期                | 例子                        |
| ------ | ------------------- | ------------------------- |
| 内置命名空间 | 启动 Python 时创建，退出时销毁 | print(), len(),ValueError |
| 全局命名空间 | 模块被加载时创建,直到脚本结束     | 模块级定义的变量,函数和类             |
| 局部命名空间 | 函数被调用时创建,函数返回时销毁    | 函数内部定义的变量,行参              |
> 作用域是 Python **查找变量的顺序法则**。当你在代码里使用一个变量时，Python 会严格按照 **LEGB** 的顺序由内向外查找：
```txt
Local ──> Enclosing ──> Global ──> Built-in 
(局部)    (闭包/嵌套)     (全局)      (内置)
```
**global** 与**nonlocal**
> `global` 用来声明最外层（模块级别）的全局变量。如果全局没有，Python 会自动在全局创建一个。
> `nonlocal` 用来声明**外层嵌套函数**里的变量（不包括全局变量）。**变量必须存在！** 如果外层嵌套函数里找不到该变量，Python 会直接报语法错误。

```python
x = "全局变量"

def outer():
    x = "外层局部变量"
    
    def inner():
        global x  # 强行绑定最外层的 x
        x = "我被 inner 修改了"
        
    inner()
    print("outer 里的 x:", x)

outer()
print("最外层的 x:", x)

# ─── 输出结果 ───
# outer 里的 x: 外层局部变量  <-- outer 里的 x 没被影响
# 最外层的 x: 我被 inner 修改了 <-- 最外层的全局 x 被改了
```
