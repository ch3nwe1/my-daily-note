## 命名空间与作用域
> 命名空间本质上是一个**字典（Dictionary）**，里面存的是 `变量名 -> 对象引用` 的映射。Python 中主要有三种命名空间：

| 命名空间   | 声明周期                | 例子                        |
| ------ | ------------------- | ------------------------- |
| 内置命名空间 | 启动 Python 时创建，退出时销毁 | print(), len(),ValueError |
| 全局命名空间 | 模块被加载时创建,直到脚本结束     | 模块级定义的变量,函数和类             |
| 局部命名空间 | 函数被调用时创建,函数返回时销毁    | 函数内部定义的变量,行参              |
> 作用域是 Python **查找变量的顺序法则**。当你在代码里使用一个变量时，Python 会严格按照 **LEGB** 的顺序由内向外查找：
```txt
Local ──> Enclosing ──> Global ──> Built-in 
(局部)    (闭包/嵌套)     (全局)      (内置)
```
**global** 与**nonlocal**
> `global` 用来声明最外层（模块级别）的全局变量。如果全局没有，Python 会自动在全局创建一个。
> `nonlocal` 用来声明**外层嵌套函数**里的变量（不包括全局变量）。**变量必须存在！** 如果外层嵌套函数里找不到该变量，Python 会直接报语法错误。

```python
x = "全局变量"

def outer():
    x = "外层局部变量"
    
    def inner():
        global x  # 强行绑定最外层的 x
        x = "我被 inner 修改了"
        
    inner()
    print("outer 里的 x:", x)

outer()
print("最外层的 x:", x)

# ─── 输出结果 ───
# outer 里的 x: 外层局部变量  <-- outer 里的 x 没被影响
# 最外层的 x: 我被 inner 修改了 <-- 最外层的全局 x 被改了
```


### 属性引用与实例化
类对象包含两种操作：**属性引用**和**实例化**
**属性引用**使用`obj.name`语法
```python
class MyClass:
    """一个简单的示例类"""
    i = 12345

    def f(self):
        return 'hello world'
```
`MyClass.i`和`MyClass.f`都属于类的属性，返回的是一个整数和一个函数(**function**)

**实例化**
```python
x = MyClass()
```
该实例化操作会创建一个空对象，如果希望创建对象实例是根据特定初始状态定制的，可以定义一个`__init__()`方法
```python
def __init__(self):
	self.data = []
```
`self`是约定的变量名，代表创建对象实例本身，可以换成其他名，比如**this**,但是一般情况下不这么做
也可以在init中传入其他参数，实现对象实例的定制化
```python
class Complex:  
    def __init__(self, realpart, imagpart):  
        self.r = realpart  
        self.i = imagpart  
  
x = Complex(3.0, -4.5)  
print(x.r) # 3.0  
print(x.i) # -4.5
```

### 实例对象
实例对象能操作属性引用，包括**数据属性**和**方法**(**method**)
**数据属性**无需声明；与局部变量 一样，它们在首次赋值时就会出现,例如上述实例**x**
```python
x.coounter = 1 # MyClass中并未声明变量counter
while x.counter < 10:
	x.counter = x.counter *2 # 可以修改
print(x.counter) # 16
del x.counter # 删除实例x的属性
```

**方法**(`x.f`)属于实例，与函数(MyClass.f)有一些区别
- `x.f`称之为**method**,MyClass.f称之为**function**
- 方法可以直接调用，函数需要传入类实例对象
### 类变量与实例变量
>实例变量用于每个实例的唯一数据，而类变量用于类的所有实例共享的属性和方法
```python
class Dog:  
    kind = 'canine'  
  
    def __init__(self, name):  
        self.name = name  
  
dog1 = Dog('Fibo')  
dog2 = Dog('Buddy')  
  
print(dog1.kind)  # canine
print(dog2.kind)  # canine
  
print(dog1.name)  # Fibo
print(dog2.name)  # Buddy	
```

> 如果你通过“实例名”去修改一个类变量，Python 不会修改类变量，而是会偷偷创建一个同名的“实例变量”！

```python
dog1.kind = 'dog'  
print(dog1.kind)  # dog  看似修改成功了，实则创建一个dog1的实例变量kind
print(dog2.kind)  # canine 没有发生改变
```

> 如果同样的属性名称同时出现在实例和类中，则属性查找会优先选择实例:

```python
class WareHouse:  
    purpose = 'storage'  
    region = 'west'  
  
w1 = WareHouse()  
print(w1.purpose, w1.region) # storage west  
  
w2 = WareHouse()  
w2.region = 'east'  
print(w2.purpose, w2.region) # storage east  
  
print(WareHouse.purpose, WareHouse.region) # storage west
```
### 继承

语法：
```python
class DerivedClassName(BaseClassName):
	statement-1
	.
	.
	.
	statement-N
```

> 在 Python 中实现继承非常简单，只需要在定义子类时，将父类名字放在括号里即可。

```python
class Animal:  
  
    def __init__(self, name):  
        self.name = name  
  
    def eat(self):  
        return f'{self.name} is eating'  
class Dog(Animal):  
    def bark(self):  
        return f'{self.name} is barking'  
dog = Dog('qiuqiu')  
print(dog.name) # qiuqiu  
print(dog.eat()) # qiuqiu is eating  
print(dog.bark()) # qiuqiu is barking
```

> 如果子类不想原封不动地使用父类的方法，可以对其进行**重写（Override）**。如果你想在子类中扩展父类的行为，而不是完全抹杀父类，就需要用到 `super()`。

```python
class Bird(Animal):  
  
    def __init__(self, name, wingspan):  
        super().__init__(name)  
        self.wingspan = wingspan  
  
    def eat(self):  
        parent_eat = super().eat()  
        return f'{parent_eat}, wingspan is {self.wingspan}'  
  
sparrow = Bird('sparrow', '15cm')  
print(sparrow.eat()) # sparrow is eating, wingspan is 15cm
```

> 如果父类和子类拥有同样的属性名,后定义的属性会覆盖先定义的属性

```python
class Bird(Animal):  
  
    def __init__(self, name, wingspan):  
        super().__init__(name)  # ①
        self.name = name + 'self'  # ②
        self.wingspan = wingspan
```
> ① 如果在前面，name属性就会包含self，②覆盖了①
> ②如果在前面，name属性不包含self，①覆盖了②

> **Python 支持多重继承**，即一个子类可以同时继承多个父类。
```python
class Flyer:  
    def fly(self):  
        return "fly"  
  
class Swimmer:  
    def swim(self):  
        return "swimmer"  
  
class Duck(Flyer, Swimmer):  
    pass  
  
d = Duck()  
print(d.fly(), d.swim())
```

> 当多个父类拥有同名方法时，Python 该听谁的？ 为了解决这个问题，Python 采用了一套名为 **C3 线性化算法** 的机制，计算出 **MRO（Method Resolution Order，方法解析顺序）**。
```python
class A:  
    def test(self):  
        print("A")  
  
class B(A):  
      
    def test(self):  
        print("B")  
  
class C(A):  
      
    def test(self):  
        print("C")  
  
class D(B,C):  
    pass  
  
d = D()  
print(d.test()) # ???
```

这里输出会是什么？？？
可以通过`mro`函数了解其查找顺序

```python
print(D.mro())
# [<class '__main__.D'>, <class '__main__.B'>, <class '__main__.C'>, <class '__main__.A'>, <class 'object'>]
```
意味着先找B,再找C,再找A,所以答案是**B**

但是Python官网说的话令人费解
> 在最简单的情况下，你可以认为搜索从父类所继承属性的操作是深度优先、从左到右的，当层次结构存在重叠时不会在同一个类中搜索两次。 因此，如果某个属性在 `DerivedClassName` 中找不到，就会在 `Base1` 中搜索它，然后（递归地）在 `Base1` 的基类中搜索，如果在那里也找不到，就将在 `Base2` 中搜索，依此类推。

### 私有变量

> 在 Python 中，以双下划线 `__` 开头的属性和方法是**私有的（Private）**。
> **私有属性不会被子类继承，子类无法直接访问它们。**

```python
class Parent:  
    def __init__(self):  
        self.public_val = "公开"  
        self.__private_val = "秘密"  # 私有属性  
  
class Child(Parent):  
    def show(self):  
        print(self.public_val)     # 正常访问  
        print(self.__private_val)  # 报错：AttributeError  
  
c = Child()  
c.show()
```

- **背后的原理：** Python 实际上对私有变量进行了“名称改装（Name Mangling）”，`__private_val` 在内部变成了 `_Parent__private_val`。
-  如果你希望属性对外部保密，但**允许子类访问**，应该使用单下划线 `_`（这是一种半私有的保护约定）。意味着你使用单下划线就可以

## dataclass

没有**dataclass** 之前,如果你想定义一个普通的 `User` 类，包含姓名、年龄和专属 ID，你不得不这样写
```python
class OldUser:
    def __init__(self, name: str, age: int, user_id: int):
        self.name = name
        self.age = age
        self.user_id = user_id

    # 为了让打印时不显示模糊的内存地址 <__main__.OldUser object at 0x...>
    def __repr__(self):
        return f"OldUser(name={self.name!r}, age={self.age!r}, user_id={self.user_id!r})"

    # 为了能让两个属性相同的对象进行对比（user1 == user2）
    def __eq__(self, other):
        if not isinstance(other, OldUser):
            return NotImplemented
        return (self.name, self.age, self.user_id) == (other.name, other.age, other.user_id)
```

使用**dataclass**
```python
import dataclasses  
  
@dataclasses.dataclass  
class User:  
    name: str  
    age: int  
    user_id: int  
  
user1 = User('Alice', 12, 1001)  
user2 = User('Alice', 12, 1001)  
  
print(user1) # User(name='Alice', age=12, user_id=1001)  
print(user2) # User(name='Alice', age=12, user_id=1001)  
print(user1 == user2) # True
```

> 你可以直接给字段赋默认值，但要注意：**有默认值的字段必须写在没有默认值字段的后面**（就像函数的参数规则一样）。
```python
@dataclass
class Product:
    name: str
    price: float = 0.0  # 默认值
```

>如果你想让默认值是一个列表或字典等可变对象，直接写 `tags: list = []` 是会报错的。你需要使用 `field` 和 `default_factory`
```python
from dataclasses import dataclass, field  
  
@dataclass  
class Article:  
    title: str  
    # 这样每个实例都会获得一个独立的空列表，互不干扰  
    tags: list = field(default_factory=list)
```

> 如果你希望数据类一旦创建就不能被修改（类似于只读的元组），可以开启 `frozen=True`。
```python

from dataclasses import dataclass  
  
  
@dataclass(frozen=True)  
class ImmutablePoint:  
    x: int  
    y: int  
  
pt = ImmutablePoint(10, 20)  
# pt.x = 30  # 报错：FrozenInstanceError: cannot assign to field 'x'
```

> `dataclass` 提供了快捷函数，可以轻松把对象解构为标准的 Python 字典或元组，非常适合用于序列化或返回 API 数据。
```python
from dataclasses import asdict, astuple

user = NewUser("Bob", 30, 1002)

print(asdict(user))   # 输出: {'name': 'Bob', 'age': 30, 'user_id': 1002}
print(astuple(user))  # 输出: ('Bob', 30, 1002)
```
# yield

> 为什么需要 `yield`？（痛点场景）

假设你需要写一个函数，生成从 1 到 100 万的数字列表

```python
def create_huge_list():
    result = []
    for i in range(1000000):
        result.append(i)
    return result  # 一次性把 100 万个数字全部装进内存
```
* **代价：** 你的计算机内存会瞬间被这个巨大的列表吃掉很大一部分。如果数字变成 1 亿，程序直接就崩溃（OOM）了。

使用 `yield`
```python
def create_huge_stream(): 
	for i in range(1000000): 
		yield i # 每次只“吐出”一个数字，然后暂停
```

当一个函数内部包含了 `yield` 关键字，这个函数就变成了一个**生成器函数**。执行这个函数时，它**不会真的运行内部代码**，而是返回一个生成器对象。

想要获取数据，你需要使用 `next()` 函数或者用 `for` 循环去遍历它。
