# 文本
除了数字 Python 还可以操作文本（由 [`str`](https://docs.python.org/zh-cn/3.14/library/stdtypes.html#str "str") 类型表示，称为"字符串"）。这包括字符 "`!`", 单词 "`rabbit`", 名称 "`Paris`", 句子 "`Got your back.`" 等等 "`Yay! :)`"。 它们可以用成对的单引号 (`'...'`) 或双引号 (`"..."`) 来标示，结果完全相同[^2]

![](../assets/Pasted%20image%2020260515150309.png)

要标示引号本身，我们需要对它进行“转义”，即在前面加一个 `\`。或者，我们也可以使用不同类型的引号:
![](../assets/Pasted%20image%2020260515171832.png)
在 Python shell 中，字符串定义和输出字符串看起来可能不同。 [`print()`](https://docs.python.org/zh-cn/3.14/library/functions.html#print "print") 函数会略去标示用的引号，并打印经过转义的特殊字符，产生更为易读的输出:
![](../assets/Pasted%20image%2020260515172730.png)

如果不希望前置 `\` 的字符转义成特殊字符，可以使用 _原始字符串_，在引号前添加 `r` 即可：
![](../assets/Pasted%20image%2020260515172901.png)

字符串字面值可以跨越多行。 一种做法是使用三重引号: `"""..."""` 或 `'''...'''`。 行结束符会自动包括在字符串中，但可以通过在行尾添加 `\` 来避免此行为。在下面的例子中，开头的换行符将不会被包括:
![](../assets/Pasted%20image%2020260515173119.png)

字符串可以用 `+` 合并（粘到一起），也可以用 `*` 重复：
![](../assets/Pasted%20image%2020260515174738.png)

相邻的两个或多个 _字符串字面值_ （引号标注的字符）会自动合并：
![](../assets/Pasted%20image%2020260515175037.png)

 拼接分隔开的长字符串时，这个功能特别实用：
 ![](../assets/Pasted%20image%2020260515175602.png)

拼接只能用于字面量的值，不能用于变量或表达式

合并多个变量或合并变量与字面值，要用`+`
```python
>>> prefix + 'thon'

```
字符串支持索引（下标访问），第一个字符的索引是0，单字符串没有专用的类型，就是长度为1的字符串（没有java中的`char`类型）。
![](../assets/Pasted%20image%2020260518111946.png)

索引还支持负数，用负数索引时，从右边开始计数：
![](../assets/Pasted%20image%2020260518112251.png)
>  注意：-0和0时一样的，都是第一个字符

除了索引草所，还支持切片，索引获取单个字符，切片用来获取子字符串
![](../assets/Pasted%20image%2020260518113523.png)

切片索引的默认值很有用，省略开始索引时默认值是0，省略结束索引时，默认到字符串结尾
![](../assets/Pasted%20image%2020260518113940.png)

还可以这样理解切片，索引指向的是字符 _之间_ ，第一个字符的左侧标为 0，最后一个字符的右侧标为 _n_ ，_n_ 是字符串长度。例如：
```txt
 +---+---+---+---+---+---+
 | P | y | t | h | o | n |
 +---+---+---+---+---+---+
 0   1   2   3   4   5   6
-6  -5  -4  -3  -2  -1
```
第一行数字是字符串中索引 0...6 的位置，第二行数字是对应的负数索引位置。_i_ 到 _j_ 的切片由 _i_ 和 _j_ 之间所有对应的字符组成。
对于使用非负索引的切片，如果两个索引都不越界，切片长度就是起止索引之差。例如， `word[1:3]` 的长度是`3-1=2` 

索引越界会报错，但切面会自动处理越界索引
![](../assets/Pasted%20image%2020260518114733.png)


Python字符串不支持修改，因此某个索引赋值就会报错

![](../assets/Pasted%20image%2020260518144459.png)

内置函数 [`len()`](https://docs.python.org/zh-cn/3.14/library/functions.html#len "len") 返回字符串的长度

![](../assets/Pasted%20image%2020260518144621.png)

# 列表
Python 支持多种 _复合_ 数据类型，可将不同值组合在一起。最常用的 _列表_ ，是用方括号
<b>[   ]</b>标注，逗号分隔的一组值。_列表_ 可以包含不同类型的元素，但一般情况下，各个元素的类型相同：
![](../assets/Pasted%20image%2020260518145209.png)

和字符串一样，支持索引和切片

![](../assets/Pasted%20image%2020260518145620.png)

和字符串不同的是**列表**是可变的，支持索引和切片的方式修改

![](../assets/Pasted%20image%2020260518145933.png)

也可以通过`append`方法向列表末尾追加元素

![](../assets/Pasted%20image%2020260518150101.png)

Python 中的简单赋值绝不会复制数据。 当你将一个列表赋值给一个变量时，该变量将引用 _现有的列表_。你通过一个变量对列表所做的任何更改都会被引用它的所有其他变量看到。

![](../assets/Pasted%20image%2020260518150646.png)

切片操作返回包含请求元素的新列表。以下切片操作会返回列表的 [浅拷贝](https://docs.python.org/zh-cn/3.14/library/copy.html#shallow-vs-deep-copy)：

![](../assets/Pasted%20image%2020260518150936.png)

为切片赋值可以改变列表大小，甚至清空整个列表：
![](../assets/Pasted%20image%2020260518151552.png)


[^1]: `**` 比 `-` 的优先级更高, 所以 `-3**2` 会被解释成 `-(3**2)` ，因此，结果是 `-9`。要避免这个问题，并且得到 `9`, 可以用 `(-3)**2`。
