# for语句
for语句用于迭代列表或字符串
```python
# 遍历列表
words = ['cat', 'window', 'defenestrate']  
for w in words:  
    print(w, len(w))
############### 输出  #################
cat 3
window 6
defenestrate 12
```
```python
# 遍历json对象
users = {'Hans': 'active', 'Éléonore': 'inactive', '景太郎': 'active'}  
for user,status in users.items():  
    print(user, status)
#######################################
Hans active
Éléonore inactive
景太郎 active

```
```python
# 遍历字符串
foo = 'Hello World'  
for char in foo:  
    print(char)

e

l
o
 
W

d
```
